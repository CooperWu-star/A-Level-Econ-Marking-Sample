# CIE Economics — Essay Templates

These are skeleton structures for the most common 12-mark question patterns. They are starting points, not formulas — every essay still needs to be tailored to the specific question. Use them when planning so the answer doesn't drift.

## Pattern 1: "Discuss whether [policy X] is the most effective way to achieve [objective Y]"

**Plan skeleton:**
```
Define: policy X, objective Y
Diagram: showing the policy's intended effect on Y
Para 1: How X works in theory — mechanism + diagram
Para 2: Why X might be effective in this case — application
Evaluation 1: Limits of X — magnitude, time lags, side effects
Evaluation 2: Alternative policy Z — how it compares
Conclusion: X is more effective when [condition]; otherwise Z
```

**A* moves:**
- Compare X to at least one credible alternative — examiners reward this directly.
- The conclusion must name the condition under which X wins. "Monetary policy is more effective in a closed economy with stable expectations; fiscal policy is preferred when the interest rate is at the zero lower bound."

## Pattern 2: "Evaluate the view that [statement]"

**Plan skeleton:**
```
Define: terms in the statement
Diagram: supporting the statement
Para 1: The case FOR the statement — mechanism + evidence
Para 2: The case AGAINST — counter-mechanism + diagram if useful
Evaluation: which side is stronger, and why, under what conditions
Conclusion: agree / disagree with the statement, conditionally
```

**A* moves:**
- Do not write a balanced "on the one hand, on the other hand" answer with no judgement. CIE rewards a position.
- The "under what conditions" line is where Level 4 evaluation happens.

## Pattern 3: "To what extent does [X] cause [Y]"

**Plan skeleton:**
```
Define: X, Y
Diagram: linking X to Y
Para 1: The mechanism by which X causes Y
Para 2: Other causes of Y (W, V) — how significant relative to X?
Evaluation: relative magnitude, time horizon, context
Conclusion: X is a significant but not sole cause; most important when [condition]
```

**A* moves:**
- "To what extent" is *literally* asking for a magnitude judgement. Answer it: "to a large extent in the short run, but to a limited extent in the long run because…"
- Name at least two alternative causes and weigh them.

## Pattern 4: "Explain how [X] affects [Y]" (8-mark Explain part)

**Plan skeleton (no evaluation needed):**
```
Define: X, Y
Diagram: showing X → Y
Para 1: Primary effect — chain of reasoning from X to Y, integrated with diagram
Para 2: Secondary effect or qualification (depth, not evaluation)
```

**A* moves:**
- Depth, not breadth. One well-developed mechanism beats three shallow ones.
- The diagram should be the centre of the answer, not an afterthought.
- Do NOT evaluate — that's for the 12-mark part. Spending time evaluating here wastes time without earning marks.

## Pattern 5: Data response (a)–(e) on Paper 4

For data response, the structure is given by the question parts. Key rules:

- **(a) Define / identify (2 marks):** One sentence each. Quote the data where relevant.
- **(b) Calculate (3 marks):** Show formula, show working, give answer with units. A correct answer with no working may still score full marks; an incorrect answer with correct working can score method marks.
- **(c) Explain (4 marks):** Single mechanism, applied to the extract. Reference at least one specific piece of data.
- **(d) Analyse (6 marks):** Diagram + developed chain of reasoning + application. This is essentially a mini 8-mark Explain.
- **(e) Discuss (8 marks):** Mini-essay. Analysis + evaluation + conclusion. Must use the extract.

Across the whole data response, the extract must appear in every part from (c) onwards. Answers that ignore the extract are heavily penalised.

## Common command words

| Command word | What it asks for | Mark allocation typical |
|---|---|---|
| Identify / State | Recall, no explanation | 1–2 |
| Define | Precise economic meaning | 2 |
| Calculate | Numerical answer with working | 2–4 |
| Explain | Mechanism, no evaluation | 4–8 |
| Analyse | Developed mechanism with diagram | 6–8 |
| Discuss | Analysis + evaluation + conclusion | 8–12 |
| Evaluate | Weigh arguments, conditional judgement | 8–12 |
| To what extent | Magnitude judgement | 8–12 |
| Assess | Similar to evaluate; weigh and judge | 8–12 |

Match the depth of your answer to the command word. "Explain" with extensive evaluation is wasting time; "Discuss" without evaluation caps the answer at Level 2.
